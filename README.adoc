== About The Project

**Antora Live** is the product home for a Confluence-like authoring layer beside Antora’s static site generator: a database for drafts and concurrent edits, an AsciiDoc source editor, and export into git so `antora generate` (Facto stack) remains production truth.

Status:: *Design filing (P0)* — architecture docs only. No runtime server or editor yet.

Canonical short link for PRs:: https://docs.antora-supplemental.org/docs/live-docs/[Live docs] on the org hub.

This is **not** https://github.com/antora-supplemental/page-edit[`page-edit`] (bake-time VCS View | Edit links) and **not** a fork of Antora core.
